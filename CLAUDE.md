# Skills repo

## Keep the README in sync

Whenever you add a skill, change one, rename or move one, or add or remove files in a skill's folder, update `README.md` in the same branch before finishing:

- **Available Skills table:** one row per skill, with an accurate description and `Key Files`.
- **Skill Details:** a `####` section per skill covering key components, requirements, features, and usage. Edit it when behavior, requirements, or files change.
- **Project Structure tree:** match the real folder layout, including the domain folder the skill lives in.

Do this even when the change looks small. If a change does not affect anything the README describes, say so in the final message instead of skipping silently.
