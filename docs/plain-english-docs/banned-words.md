# Agent English ban list

Add a line whenever the user catches a new word or phrase. Format: `banned → replacement`. Use `cut` when the best fix is to delete it.

## Words and phrases

- leverage → use
- utilize → use
- robust → cut, or say what it withstands
- seamless → cut, or say what the reader does not have to do
- streamline → simplify, or cut
- delve → look at
- comprehensive → full, or cut
- note that → cut, or make it its own sentence
- it's important to → cut, and say the instruction
- as mentioned above → name the thing again, or cut

## Plain-word swaps

- suboptimal → wrong, or slow, or costly. Say which.
- prior to → before
- in order to → to

## Never in an instruction

- simply → cut
- just → cut
- easy → cut
- please → cut

## Dash

- — (em dash) → full stop
